## ✨ Features

- **Universal AI Chat** → Claude 3.5, Grok, GPT-4o etc.
- **Smart Summarizer** → Text, Articles, PDFs
- **Code Assistant** → Generate + Explain Code
- **Idea & Content Generator** → Business, Social Media, YouTube
- **Image Prompt Enhancer**
- **Research Agent**
- Beautiful Dark Glassmorphism UI
- Chat History
- Fully Responsive (Mobile + Desktop)

## 🚀 Quick Start

```bash
git clone https://github.com/Gourav-512/MindMatrixio.git
cd MindMatrixio
npm install
cp .env.example .env.local
# Add your API keys in .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📁 Project Structure


## 🛠️ Tech Stack

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Backend**: PHP + Python
- **AI**: OpenRouter, Grok (xAI), and other LLMs
- **UI**: Dark Glassmorphism design
